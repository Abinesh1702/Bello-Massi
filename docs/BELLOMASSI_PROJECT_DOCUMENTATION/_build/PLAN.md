# Build plan and checklist (A–Z documentation package)

Source brief: 3b9989c7-attachment.txt. Work in batches; keep this checklist current.

Approach
- Every document is authored as Markdown with YAML front matter in `_build/src/<folder>/<DOC-ID>_<Name>.md`.
- `_build/build.py` adds the standard document-control block (title, ID, version, status, prepared/reviewed/approved, dates,
  purpose, scope, definitions, references) and revision history, then writes `<folder>/<file>.md`, `.docx`, and `.pdf` (when `pdf: true`).
- Spreadsheets are generated by `_build/xlsx_*.py` with openpyxl from `_build/data/*.py|json`.
- Diagrams: Mermaid sources in `21_DIAGRAMS_AND_VISUAL_DOCUMENTATION/mermaid/*.mmd`, rendered to SVG + PNG.
- Labels: VERIFIED · PROTOTYPE · PROPOSED · PENDING CONFIRMATION · NOT IMPLEMENTED · NOT VERIFIED.
- Never: fake signatures, approvals, UAT completion, live integrations, real costs (estimates are marked).
