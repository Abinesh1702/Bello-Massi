## 4. Environments and data

Test and staging environments as {{ref:BM-INF-003}}. Synthetic data only; no production personal data in test. Provider
sandboxes for integrations. Fixed seed for repeatable automated runs.

## 5. Entry and exit criteria

| Phase | Entry | Exit |
|---|---|---|
| System test | Build deployed to test; smoke passed; test cases reviewed | 100 % planned cases executed; no open Critical / High; Medium with agreed workaround |
| UAT | System test exit met; UAT users trained; UAT data loaded | All UAT cases executed; no open Critical / High; client sign-off ({{ref:BM-QA-003}}) |
| Release | UAT signed; release checklist complete | Go-live approval ({{ref:BM-DEP-001}}) |
