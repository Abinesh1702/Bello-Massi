## 1. Meeting minutes template

| Field | Content |
|---|---|
| Meeting | Title, date, time, location / link |
| Attendees | Name, organisation, role |
| Absent |  |
| Agenda | 1 … n |
| Discussion summary | Per agenda item |
| Decisions | DEC-ID, decision, decided by (copy to decision log) |
| Actions | Action, owner, due date, status |
| Risks / issues raised | Copy to registers |
| Next meeting |  |

## 2. Sprint planning template

| Field | Content |
|---|---|
| Sprint | Number, start, end |
| Sprint goal | One sentence |
| Capacity | Team members × available days |
| Backlog items | ID, title, FR reference, estimate (points), owner |
| Dependencies / risks |  |
| Definition of done | As in {{ref:BM-PM-001}} §6 |
| Review date / demo items |  |

## 3. Status report template

| Section | Content |
|---|---|
| Period | From – to |
| Overall status | Green / Amber / Red with reason |
| Progress | Completed this period; planned next period |
| Milestones | Planned vs forecast date |
| Risks and issues | Top 5 with actions |
| Decisions needed | From whom, by when |
| Change requests | New / approved / rejected |
| Budget (if applicable) | Planned vs actual |
