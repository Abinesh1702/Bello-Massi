## 1. Proposed warranty

| Item | Proposal |
|---|---|
| Period | 90 days from production go-live |
| Covered | Defects where the system does not meet accepted requirements (UAT baseline) |
| Not covered | New requirements, changes after acceptance, third-party outages, misuse, infrastructure managed by others, data quality issues |
| Prototype | Provided for demonstration and requirement validation only — not for production use |
| Remedy | Correction or workaround per support severity levels ({{ref:BM-HND-014}}) |

## 2. Exclusions related to known limitations

Limitations listed in {{ref:BM-HND-011}} are not defects of the prototype.
