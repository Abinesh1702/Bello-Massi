## 1. Key terms

| Term | Meaning |
|---|---|
| Order Taking App | Office / mobile application for salesmen, Sales Manager, Customer Service and Dispatcher |
| Drivers App | Mobile application for drivers |
| Admin Panel | Web application for administration and monitoring |
| Consolidation | Customer Service verification and release of approved orders |
| Dispatch | One vehicle run from one hub on one date with a driver and stop sequence |
| OTP | One-time password the customer gives the driver to confirm handover |
| POD | Proof of delivery: quantities, receiver, signature, photo |
| Delivery note | Document issued when a stop is completed |
| Zone | Group of pincodes served from a hub |
| VMS | Vehicle Management System — document compliance of vehicles and drivers |
